# Платформа ЕЦП

Демонстрационная версия внутренней платформы ГБУ «Единый центр поддержки»: главная страница, настройки и три сервиса.

- **Электронная очередь**: отчёт по юридической консультации (снимок данных, сотрудники обозначены талонами).
- **Ежедневные отчёты**: операционные показатели подразделений (снимок данных, без выгрузки и редактирования).
- **Адаптация сотрудников**: курс для новых сотрудников.

ФИО сотрудников заменены на «Тест». Профиль из настроек хранится только в браузере.
